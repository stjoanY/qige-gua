# 《起个卦 · 总设计案》 v1.0

创意总监 游有方 · P1 立项产出 · 基于用户已确认的 P0.5 复述展开
（主理人存档 2026-10-20，验收通过；见文末主理人仲裁备注）

═══════════════════════════════
一、核心设计概览
═══════════════════════════════

**一句话卖点**：像随身带了一座小道观——摇一摇就出签，签有诗、解有据、凶有路。

**目标体验**：三分钟一次的心灵小仪式。用户在任何碎片时刻打开，摇签→读签→（必要时）化解→安心离开。核心情绪不是"求好运"，而是"得一个说得通的说法 + 一条能做的事"。

**设计支柱（所有后续决策以此为准绳）**：
1. **卦不妄成**：任何吉凶结论都能追溯到体用生克，同输入必同输出
2. **凶签给路不给判决**：下下签是全站文案质量要求最高的地方
3. **仪式感是玩法**：摇签的手感和化解的仪式不是包装，就是核心体验本身
4. **典雅不艳俗**：所有视觉/文案判断标准——放在博物馆文创店里不违和

三、签文库结构（64 支 ↔ 64 卦）
═══════════════════════════════

**对应方案**：一卦一签，一一对应（乾为天 = 第1签 … 火泽睽/水火既济顺序按《周易》卦序编号至第64签）。卦序即签号，不做随机映射——这样"同卦同解"天然成立。

**每支签字段规范**（静态签文 vs 动态生成的分界，按拍板 C 执行）：

```
{
  签号: 1–64（= 卦序）
  卦名: "乾为天"
  卦符: ☰☰（六爻线段图形，由程序绘制，不存图片）
  签诗: 四句七言（静态，每卦一首，全站最高质量要求的内容）
  主题: ≤6字，如"潜龙待时"（静态，签诗的诗眼提炼）
  基准吉凶指数: 30–70 区间的一个静态锚点值（每卦按卦德定，
               如乾 68、困 32；留出动态修正空间）
  解签主旨白话: 一段 60–100 字静态白话，讲这支签的核心局面（静态骨架）
  动态解签槽位: {体用关系文案, 旺衰文案, 动爻取象文案, 变卦走向文案}
               —— 四个槽位由程序按起卦结果填充（动态）
  化解建议方向: 该卦五行属性 + 受克路径 → 生成建议的静态规则引用（动态展开）
}
```

**静态/动态分界一句话**：签诗和主旨白话跟着卦走（同卦必同诗），签级和四槽位细节跟着"卦 × 日期 × 问题"走（同人同日同问必同解，异日同卦可同诗不同级）。

**签级最终判定公式（动态）**：
最终指数 = 基准吉凶指数 + 体用生克修正（-20~+20）+ 日辰旺衰修正（-10~+10），clamp 到 0–100 后查档位表。
（体用生克：用卦生体/比和 +15~+20；体克用 +8；用克体 -15~-20；体生用泄气 -5~-8。旺衰：体卦得当日五行生扶 +8~+10，受克 -8~-10。具体系数属程序实现，此处定调参区间。）

四、起卦规则（梅花易数确定性移植）
═══════════════════════════════

**A. 每日一签（无问题）**：时间起卦。年支数 + 农历月 + 农历日 → 上卦；(年+月+日) + 时辰数 → 下卦；(年+月+日+时) ÷ 6 余数 → 动爻。当日任何时候点"每日一签"，卦相同、签相同、解相同（时辰按进入页面当日首个摇签时辰锁定并存储，避免跨时辰重抽）。

**B. 带问题摇签**：字数起卦。问题总字数 ÷ 8 余数 → 上卦（先天卦数：乾1兑2离3震4巽5坎6艮7坤8，余0取8）；(字数 + 当日时辰数) ÷ 8 余数 → 下卦；(字数 + 时辰数) ÷ 6 余数 → 动爻。字数在输入框实时计数展示为"卦数"仪式的一部分。

**C. 一事一占（初筮告，再三渎）**：同一问题**同一天**再次摇签 → 不重起卦。程序对问题文本做规范化（去空格标点）后比对当日已有记录，命中则直接展示今日该问的签，页面顶部出现一行提示："今日已为此事起过一卦。卦不重起，心诚则灵。" 不同问题、或隔天再问同一问题，正常起卦。**每日一签每天限一支**，当日已抽则月历入口展示"今日之签"。

**确定性声明**：同一天 + 同一问题 = 同一卦同一签同一解，用户换个时间验证也是同一个结果——这是"卦不妄成"的信任基石，程序侧须用纯函数实现。

五、化解互动设计
═══════════════════════════════

**触发**：签级 = 中下 / 下下 时，解签卡底部浮现一枚莲花灯按钮：「化解」。

**仪式流程（约 15–20 秒，全程可跳过但默认引导完成）**：
1. **点灯**（长按 1.5 秒）：指尖长按一朵含苞莲花，莲灯渐亮、灯焰轻摇（长按松手前有微光反馈，松手即灭重来，制造"用心"的体感）
2. **静心三息**（约 12 秒）：屏幕中央一个随呼吸节奏缓缓胀缩的淡金圆环，配一行小字"随息三巡，心定则灵"，圆环三次胀缩后轻响一声磬音
3. **灯下得方**：莲灯照亮一张「化解签」——基于该卦五行与体用受克路径生成的 2–3 条可执行建议（穿衣颜色 / 方位 / 一件当日可完成的小事，见样例签第三支），落款一句："卦示其势，人行其事。愿你顺时自渡。"

**设计红线**：建议全部是"可执行的行为"（穿什么、朝哪边、做件什么小事），不出现任何"购买""付费""转发"类动作；文案不承诺改命，只给"松动局面的抓手"。

六、月历记录
═══════════════════════════════

**存储字段（localStorage 单条记录）**：
```
{ 记录id, 日期(YYYY-MM-DD), 时刻, 问题原文(可为空=每日一签),
  签号, 卦名, 签级, 最终吉凶指数, 体用关系摘要, 动爻,
  是否已完成化解仪式, 化解建议快照 }
```
（存"解签快照"而非重算，保证未来调整文案后历史记录不变——用户回看去年今日，看到的还应是当年的话。）

**月历视图**：整月网格，当日高亮。有记录的日子显示一枚**签级色点**（沿用六档视觉色：鎏金/暖金/青碧/赭黄/黛蓝/墨色——是色点不是红绿对错，杜绝"凶=刺眼大红"的廉价感）。已化解的记录在色点外加一圈细描边。点任一日 → 底部抽屉滑出当日签详情（复用出签卡片，问题原文、签诗、解签、化解状态完整回看）。多月切换，左右滑动手势。

七、黄历 + 五行穿衣
═══════════════════════════════

**内容项清单**：当日干支（年/月/日）、生肖冲煞、宜（5–6 项）、忌（3–4 项）、穿衣指南（大吉色 1 组 / 次吉色 1 组 / 慎用色 1 组，各配一件示意衣料色块）。

**宜忌生成规则框架（确定性，非随机）**：以日干支为输入 → 查建除十二神（建除由月支日支推得）定基础宜忌基调 → 叠加日五行与常用事类五行（嫁娶/开市/出行/动土/祈福/理发等 12 个事类）的生克关系筛选。规则表内嵌本地，同一日子全网算出来一个样。此处只定框架，细则规则表由我与程序侧在 P2 前联合定稿。

**五行穿衣映射（以当日日干五行 N 为基准）**：
- 大吉色 = 生 N 之色 + 与 N 同行之色（如 N=水：金生水+水比和 → 白/银 + 黛蓝/墨黑）
- 次吉色 = N 所生之色（水生木 → 青碧/竹绿）
- 慎用色 = 克 N 之色（土克水 → 土黄/赭褐）
- 颜色一律用**国风雅色版**呈现（水不是 #000000，是黛蓝/墨青；金不是亮黄，是月白/银灰/鎏金），每组色给国风色名 + 色块，如"黛蓝 · 沉静如夜雨"。

八、文案基调规范
═══════════════════════════════

- **白话**：解签禁用"大凶""必遭"等判词；用"眼下受阻""建议缓行""转机在即"
- **温暖不说教**：永远站在用户这边，"你"字多于"你应"
- **不宿命**：每个凶签的文案重心落在"能做什么"，凶的局面描述不超过整段 40%
- **免责声明（一句话版，页脚常驻）**："起个卦 · 内容参考传统易学文化，仅供文化体验与自省之趣，人生大事请以理性与专业意见为准。"

十一、风险与可砍项
═══════════════════════════════

- **风险①**：64 支签诗是最大内容量，质量不齐会砸"卦不妄成"招牌 → 对策：先产 8 支覆盖吉平凶的种子签跑通全流程，其余分批，每批过我的文案审
- **风险②**：农历/建除规则移植出错会让黄历全错 → 对策：规则表我逐条核对方可上线；P1.5 灰盒阶段先验证若干已知日期
- **风险③**：化解仪式若过长会烦 → 对策：三息环节总长控制在 12 秒内，且保留"跳过"入口
- **可砍项（若工期紧张）**：多手指滑动切月（先按钮切月）、签级色点描边（先纯色点）、次吉色组（先大吉+慎用两档）——均不影响核心循环
