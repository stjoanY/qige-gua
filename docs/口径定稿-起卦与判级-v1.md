## 一、问事签起卦公式（定稿：「字数起卦 · 掺时辰」变体）

**口径依据**：经典梅花《梅花易数》「物数占／声音占」——"以可数之数起上卦，以时数配作下卦"；多字问事取「多字占」前后半分卦。此公式即主理人仲裁的"字数掺时辰"方案的具体化，非我架构案原 A 方案（原 A 为纯字数不掺时辰）。

### 1.1 文本规范化（归一化，消除排版差异）
1. 去除首尾空白；
2. 连续空白（空格/换行/制表）折叠为单个半角空格；
3. Unicode NFKC 归一化（全角→半角等，确定性操作）；
4. 字数 n = 规范化后文本的 Unicode 码点数（`Array.from(text).length`）；
5. 输入上限 50 字（与记录 schema 的 `q` 字段一致），UI 层截断。

### 1.2 起卦公式（设抽签时刻时支数为 H，子1..亥12；前半字数 a=⌈n/2⌉，后半字数 b=⌊n/2⌋）

```
上卦 = a % 8          （余 0 取 8）
下卦 = (b + H) % 8    （余 0 取 8）
动爻 = (n + H) % 6    （余 0 取 6）
```

**可解释叙事**（可向用户展示的算式，"卦不妄成"）：你问了 n 字，前 a 字为上卦，后 b 字加时数起下卦，总字数加时数定动爻。

**边界**：n=1 → a=1, b=0（下卦=时支数%8）；空文本不进入问事签（走每日一签）。

**确定性范围**：同问 + 同时辰 + 同日 → 完全同签（签级还随月令旺衰逐日浮动，同问隔日签级可不同——"卦还是那个卦，时势变了"）。跨时辰重问同题会得新卦，这正是掺时辰的用意（经典梅花本就如此），复占提示文案按游有方修订版执行。

**与参考引擎对拍衔接**：本公式精确映射 `meihua.py num A B C` 三数起卦（A=a，B=b+H，C=n+H），对拍可直接生成基准用例，无需引擎改动。

## 二、每日一签公式（已仲裁采纳，此处定稿备案）

时间起卦，**固定午时**（时支数=7）：上卦=(年支数+农历月+农历日)%8（余0取8）；下卦=(和+7)%8（余0取8）；动爻=(和+7)%6（余0取6）。月支取近似节气口径（与参考引擎一致）。同一天全国同签，全天唯一。

## 三、问题哈希掺不掺 → **不掺**（定稿）

理由：
1. **可解释性是产品核心卖点**——"同卦同解、不瞎编"依赖用户能理解"卦从哪来"。"你的问题 12 字"可验证、可向朋友复述；哈希不可解释，会削弱而非增强"真"感。
2. 掺时辰后，同字数问题在**不同时辰/不同日**已天然分化（下卦、动爻随时辰变，签级随月令变）；同时辰同时段的同字数碰撞在真实使用中低频，且同卦同解本就是设计哲学，不视为缺陷。
3. 工程上少一段哈希实现与测试面，且不破坏「字数起卦」的经典叙事完整性。
（此决定与主理人倾向一致，机制上我同时确认：掺哈希的收益不足以抵消叙事损失。）

## 四、判级矩阵（七档定稿，替代架构案 §3.4 占位）

### 4.1 机制

```
s = 主卦体用关系分 + 体卦月令旺衰值

关系分：用生体 +2｜比和 +1｜体克用 0｜体生用 -1｜用克体 -2
旺衰值：旺 +1｜相 +0.5｜休 0｜囚 -0.5｜死 -1     （旺衰只看体卦——经典梅花以体卦为主）

七档分箱（阈值含下界）：
  s ≥ +2.5 → 上上        s ≥ +1.5 → 上
  s ≥ +0.5 → 中上        s ≥ -0.5 → 中
  s ≥ -1.0 → 中下        s ≥ -2.0 → 下
  s <  -2.0 → 下下
```

### 4.2 关键口径变更：变卦不入判级【TODO-游有方 复核】

游有方此前拍板"变卦升降一档修正保留"，经全量数据验证**建议取消**，理由：
1. **结构性缺陷**：变卦修正天然压缩两端——"用生体"已是最优关系无从再升、"用克体"已是最劣无从再降，上上/下下被系统性拉向中间。保留修正的所有变体，上上被封在 2.6-9.0% 且拟合全面劣化（带"七档非空"约束下 L1 16.5-20.6pct vs 无修正 13.4pct）。
2. **信息不丢失**：变卦转入**动态解签第四槽位文案**（游有方四槽位设计本就有"变卦"槽）——"本卦看当下，变卦看终局"的叙事由文案承担，档位只定"当下格局"。化解建议的措辞轻重也可由变卦槽文案体现。
（若游有方坚持档位层面保留修正，备选：仅当变卦关系**跨两档**变化时才升降一档——但数据上此折中收益有限，不推荐。）
